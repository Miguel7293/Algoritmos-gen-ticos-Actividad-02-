**Actividad 02**

&nbsp;

**Objetivo:** Comprender la aplicación de los algoritmos genéticos en el aprendizaje de máquina.

&nbsp;

**Indicaciones:**

1. En equipos de 4 estudiantes crean ejemplos sobre:  
   1. Uso de algoritmos genéticos para hallar las mejores características (optimización), también conocido como “feature selection” de un modelo de aprendizaje de máquina.  
   2. Uso de algoritmos genéticos para hallar los mejores hiper parámetros de un modelo de aprendizaje de máquina, también conocido como “Hyperparameter optimization”  
   3. Uso de algoritmos genéticos para hallar la mejor arquitectura de una red neuronal o “Neuroevolution”.  
2. Cada ejemplo muestra el ciclo de un algoritmo genético (representación de la población o cromosomas, inicialización, función de aptitud, selección, cruzamiento, mutación y terminación).  
3. El uso del lenguaje de programación y ambiente es selección del equipo (collab, notebook júpiter, código en visual code, entre otros)  
4. La evaluación es oral y de observación, se tomará en cuenta que las explicaciones son realizadas por cada uno de los integrantes del equipo y que funcionan los ejemplos creados.  
5. Sobre la evaluación:  
   1. Explicación de ejemplo de AG para *feature selection* (3 puntos)  
   2. Explicación de ejemplo de AG para *Hyperparameter optimization* (3 puntos)  
   3. Explicación de ejemplo de AG para *Neuroevolution* (3 puntos)  
   4. Funciona el ejemplo de AG para *feature selection* (3 puntos)  
   5. Funciona de ejemplo de AG para *Hyperparameter optimization* (3 puntos)  
   6. Funciona de ejemplo de AG para *Neuroevolution* (3 puntos)  
   7. Resumen ejecutivo de los realizados en un PDF entregado en el aula virtual, no más de 2 hojas, que incluye el enlace de Github donde se encuentran los ejemplos; el contenedor Github incluye el archivo README (2 puntos).  
6. **Fecha de presentación y evaluación:** Miércoles 16/09/26  
7. Orden de presentación: Alfabético (A-Z)
